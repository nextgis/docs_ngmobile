Список изменений 
================

**Версия 3.2.0 от 30.07.2026**

* Поддержка формата MBTiles для локальных растровых слоёв
* Настройка цвета подписей для полигонов и линий
* Переход к точке по координатам
* Заменить всплывающее окно при удалении объекта на модальное (с подтверждением)
* Ссылка на форму контакта с администратором Веб ГИС при недостаточных правах
* Брать название слоя из имени файла NGRC
* Ошибка синхронизации при отправке данных с пустой датой (исправлено)
* Невозможно ввести дату через форму (исправлено)
* Не отображается состояние переключения видимости трека (исправлено)
* Ошибка при попытке загрузить вложение не изображение из NGW (исправлено)
* Ненужное центрирование текста в таблице объектов (исправлено)
* Не работает отключение видимости треков (исправлено)
* Не работает изменение цвета для  отображения треков (исправлено)
* Заход в свойства слоя NGW включает авто-синхронизацию (исправлено)
* Переименовать "Your UID" в "Device ID" как в Веб (исправлено)
* Неправильное отображение чекбокса включения линейки (исправлено)

**Версия 3.1.2 от 14.07.2026**

* Убраны все запросы к охвату при добавлении растрового слоя
* Не корректное отображение включенной автосинхронизации (флажок в настройках Веб ГИС) (исправлено)

**Версия 3.1.1 от 08.07.2026**

* Понятное сообщение вместо Account is null при попытке добавить слой
* Уведомление для случая когда невозможно использовать поле формы для ввода
* Выбор поля для метки идентификации (label attribute)
* Линейка доступна по умолчанию
* Лишнее изменение геометрии при отсутствии её редактирования пользователем (исправлено)
* Смещение точки к текущей локации при создании точки (исправлено)
* Многократные запросы на получение одного слоя (исправлено)
* Подпись Contains ads в Google Play (исправлено)
* Настройки профайлинга в Sentry
