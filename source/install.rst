Installation
==================

NextGIS Mobile app can be installed from the `Google Play <https://play.google.com/store/apps/details?id=com.nextgis.mobile>`_ store or from the `APK file <https://docs.nextgis.com/docs_ngmobile/source/install.html#apk>`_.

In Google Play enter "NextGIS Mobile" in the search bar, select the app from the search results and click **Install**.

When the installation is complete the app icon is added to the screen:

.. figure:: _static/mobileappicon.png
   :name: ngmobile_launch_shortcut_pic
   :align: center
   :width: 2cm

   NextGIS Mobile icon

.. _apk:

Install from APK
-----------------------------

You can also use a downloadable file `nextgismobile.apk <http://nextgis.com/nextgis-mobile/>`_.

Allow installing apps from unknown sources in your device settings (:menuselection:`Settings > Apps & Notifications > Special App Access > Install unknown apps`). 
After the app is installed you can disable this option.
